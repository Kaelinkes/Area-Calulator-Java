# Area Calculator (Java)

A simple **menu-driven Java console application** that calculates the area of different geometric shapes using **Object-Oriented Programming principles**.

## 📌 Features
- Calculates the area of:
  - Circle
  - Triangle
  - Rectangle
- Uses an abstract base class (`Shape`)
- Demonstrates:
  - Inheritance
  - Method overriding
  - Polymorphism
- Each class is stored in its **own file** for clarity and maintainability
- User-friendly console menu
- Loop-based execution until the user chooses to exit

## 🧠 Concepts Used
- Abstract classes
- Method overriding
- Encapsulation
- `Scanner` for user input
- `Math` library for calculations
- Clean separation of logic per class
